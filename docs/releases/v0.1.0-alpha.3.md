# WatchBridge 0.1.0-alpha.3

## 中文

### 本次修复

- **弹窗黑块**：弹窗改为渲染到应用根节点，此前渲染到 `<body>` 会丢失浅色主题作用域，「管理证书」等内容显示为黑色块。
- **设置面板对比度**：Anisette Server、Language 下拉框以及「查看日志」等按钮此前沿用了深色主题的硬编码颜色，深字压深底；现已改为浅色配色，选中项、悬停状态一并修正。
- **错误弹窗按钮**：「复制到剪贴板」「忽略」在浅色主题下同样不可读，已修正；悬停不再回退成深色。
- **支持链接**：错误提示里的 Discord 与 GitHub issue 链接原先指向上游项目，现改为本仓库的 issue 页面，并移除上游 Discord 链接。

### 同时包含此前版本的修复

- 证书数量上限的弹窗曾因位于被禁用的 `<fieldset>` 内而无法点击，导致安装卡死；现通过 portal 渲染，并强制显式选择要撤销的证书。
- Watch App ID 现在会启用 App Groups 能力并完成组关联，其 provisioning profile 不再缺少 `com.apple.security.application-groups`。
- 第二次打开程序时配对失败：复用时仍然有效的会话，不再对已信任的手表重复配对。
- 新增日志导出，可一键把日志写入单个文件。
- 许可证清单脚本在 Windows 上因 CP1252 解码崩溃的问题已修复。

### 资产

`watchbridge-windows.zip`：`WatchBridge.exe`（未签名）、`BUILD.json`、`SHA256SUMS.txt`、`LICENSES.zip`。

### 注意

- 未签名、无安装包，首次运行会出现 SmartScreen 提示。
- 签名依赖 `apple-codesign-quick` 的许可仍待澄清，详见 `docs/LICENSE_REVIEW.md`。
- 登录时若出现 `Auth error -23782`，说明所选 anisette 服务器返回的 macOS 版本过低（如 10.12.6），请改用返回 13.x 的服务器。

## English

### Fixed in this release

- **Black dialog blocks**: dialogs rendered into `<body>`, which dropped the light-theme scope, so content such as the certificate manager appeared as a black block. They now render into the app root.
- **Settings contrast**: the Anisette Server and Language dropdowns and buttons such as "View logs" still used hardcoded dark-theme colours, leaving dark text on a dark surface. They now use the light theme, including the selected row and hover states.
- **Error dialog buttons**: "Copy to clipboard" and "Ignore" were unreadable on the light theme; fixed, and hovering no longer falls back to a dark surface.
- **Support links**: the Discord and GitHub issue links in the error dialog pointed at the upstream project. They now open this repository's issue tracker, and the upstream Discord link is gone.

### Included from earlier releases

- The certificate-limit dialog could not be clicked because it lived inside a disabled `<fieldset>`, which deadlocked the install. It now renders through a portal and requires an explicit certificate selection.
- Watch App IDs now enable the App Groups capability and group assignment, so their provisioning profiles no longer lack `com.apple.security.application-groups`.
- Pairing failure on the second launch: a still-valid cached session is reused instead of pairing an already trusted Watch again.
- Added log export: write the logs to a single file in one click.
- The license inventory script no longer crashes on Windows due to CP1252 decoding.

### Assets

`watchbridge-windows.zip`: `WatchBridge.exe` (unsigned), `BUILD.json`, `SHA256SUMS.txt`, `LICENSES.zip`.

### Notes

- Unsigned and no installer; SmartScreen warns on first run.
- The licence of the signing dependency `apple-codesign-quick` is still being clarified; see `docs/LICENSE_REVIEW.md`.
- `Auth error -23782` during sign-in means the selected anisette server reports an old macOS version (for example 10.12.6). Pick a server that reports 13.x.
