Windows 上的 Apple Watch 开发者模式准备与 Companion 安装助手。

## 本次包含

### 修复

- **弹窗配色。** 弹窗改为渲染到应用根节点，之前渲染到 `<body>` 会丢掉浅色主题作用域，导致「管理证书」等内容显示为黑色块；错误详情与日志文本框也补上了浅色配色。
- **证书上限弹窗不再卡死。** 弹窗此前渲染在被 `disabled` 的 `<fieldset>` 内，所有按钮都继承了禁用状态，后端又要等待 5 分钟，用户只能强制结束程序。现在弹窗通过 portal 渲染到 `<body>`。
- **撤销证书前必须显式选择。** 未选择时「继续」不可点；界面显示将撤销的数量，并提示撤销会使已签名的应用失效。只撤销选中的证书，不再默认全选。
- **Watch App 的 App Group。** 此前 Watch App ID 在启用 App Groups 能力时被跳过，导致其 provisioning profile 不含 `com.apple.security.application-groups`。现在按 watchOS 平台补齐能力启用与关联，Watch 端失败只告警、不中断安装。
- **第二次打开程序时配对失败。** 复用时仍然有效的会话，不再对已信任的手表重复配对；表名与设备类读取增加重试，读不到时不再中断流程。
- **许可证清单脚本**在 Windows 上以 CP1252 解码子进程输出会导致构建崩溃，改为显式 UTF-8 解码。

### 新增

- **日志导出**：日志弹窗内一键导出为单个文件，含版本与系统信息，上限 8 MB。
- 安装日志新增每个 profile 实际授予的 `application-groups`，用于判断签名权限是否生效。
- README 提供简体中文、English、한국어、繁體中文、日本語、Español、Français、Deutsch、Português 九个版本。

## 注意

- 未签名、无安装包，只有裸 exe。
- 已在 iPhone 17 Pro + Apple Watch Ultra 2、iPhone 13 Pro + Apple Watch Series 7 上验证完整流程。
