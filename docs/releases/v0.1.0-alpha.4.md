# WatchBridge 0.1.0-alpha.4

## What's new

### The interface now follows your system language

The app used to start in Simplified Chinese regardless of the Windows display language, and opening the settings panel could switch it to English. It now picks the OS language on first launch, maps locale codes such as `zh-CN` or `pt-BR` onto the bundled resources, and remembers an explicit choice for later launches.

### The nine main languages are fully translated

Every string the interface uses — 237 of them — now has text in each of these languages:

| Language | Text added in this release |
| --- | --- |
| English | complete already |
| 简体中文 | 98 |
| 繁體中文 | 106 |
| 日本語 | 91 |
| 한국어 | 96 |
| Français | 96 |
| Español | 111 |
| Deutsch | 111 |
| Português (BR) | 96 |

That removes the mixed-language screens in app management, automatic renewal, Wi-Fi install and pairing repair, where untranslated strings previously fell back to English.

Translations keep each file's existing register: informal *du* in German, *vous* in French, *tú* in Spanish and 합니다체 in Korean. All placeholders are preserved, so messages such as `{{code}}` or `{{stage}}` still interpolate correctly.

The other 19 bundled languages remain partially translated and fall back to English for missing strings.

## Notes

- Unsigned and no installer; only the executable.
- The licence of the signing dependency `apple-codesign-quick` is still being clarified; see `docs/LICENSE_REVIEW.md`.
- `Auth error -23782` during sign-in means the selected anisette server reports an old macOS version; pick a server that reports 13.x.
- One paired Watch per iPhone; only IPAs that contain both the iPhone host and `Watch/*.app` are supported.
