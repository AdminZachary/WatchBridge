# WatchBridge 0.1.1

A small follow-up to 0.1.0. The binaries are unchanged in behaviour except for the two fixes below; there is no new sideloading capability in this release.

## What changed

- **The main screen is translated.** Every string on the start screen — headings, step instructions, buttons, status and result messages, the attribution footer — now goes through the translation layer instead of being hardcoded. English, Korean and Simplified Chinese are complete; the remaining locales fall back to English until translations arrive.
- **Improved readability.**

## Requirements

**Windows** — Windows 10 22H2 or Windows 11 on x64, Apple Mobile Device Service (iTunes or the Apple Devices app) and the WebView2 runtime.

**macOS** — macOS 11 or newer on Apple Silicon or Intel. The system `usbmuxd` is used directly, so there is no driver to install.

Both platforms need an iPhone already paired with the target Watch, and a cable for the preparation step.

## Installing on macOS

The bundle is ad-hoc signed but not notarized. The first launch is blocked by Gatekeeper: allow it once under **System Settings → Privacy & Security → Open Anyway**, then open the app again.

## Known limitations

- The Windows executable is unsigned, so SmartScreen warns on first run; the macOS bundle is not notarized.
- Automatic renewal's "start at login" option is Windows-only.
- One paired Watch per iPhone. Only IPAs that contain both the iPhone host and `Watch/*.app` are supported.
- `Auth error -23782` during sign-in means the selected anisette server reports an old macOS version. Choose a server that reports 13.x.
- The signing dependency `apple-codesign-quick` does not declare a licence; see `docs/LICENSE_REVIEW.md`.
