# WatchBridge 0.1.3

Linux joins Windows and macOS: the same Watch preparation and companion install flow now runs on all three platforms. Thanks to @seomin0610 for the Linux port and for validating it on real hardware.

## What changed

- **Linux builds.** Releases now include a `.deb` and an `.rpm` for x86_64, built from the same source tree as the other platforms. Device communication goes through the system `usbmuxd` daemon, so no Apple software is required — the open-source daemon replaces Apple Mobile Device Service on Linux.
- **The file picker follows the desktop.** On Linux the dialogs go through xdg-desktop-portal instead of GTK, which is what makes "Choose IPA" work under GNOME, KDE and tiling window managers alike. The package declares that dependency, so `apt install` brings it in.
- **Windows and macOS are unchanged.** The dialog backend there stays the native one; the Linux switch is scoped to Linux in the dependency graph.

## Requirements

**Windows** — Windows 10 22H2 or Windows 11 on x64, Apple Mobile Device Service (iTunes or the Apple Devices app) and the WebView2 runtime.

**macOS** — macOS 11 or newer on Apple Silicon or Intel, without Xcode.

**Linux** — the `usbmuxd` daemon, WebKitGTK 4.1, a Secret Service keyring and xdg-desktop-portal. GNOME and KDE provide the last two by default.

All three need an iPhone already paired with the target Watch, and a cable for the preparation step.

## Installing on Linux

```bash
sudo apt install ./WatchBridge_0.1.3_amd64.deb    # Debian/Ubuntu
sudo dnf install ./WatchBridge-0.1.3-1.x86_64.rpm # Fedora
sudo systemctl enable --now usbmuxd
watchbridge
```

## Installing on macOS

The bundle is ad-hoc signed but not notarized. The first launch is blocked by Gatekeeper: allow it once under **System Settings → Privacy & Security → Open Anyway**, then open the app again.

## Known limitations

- The Windows executable is unsigned, so SmartScreen warns on first run; the macOS bundle is not notarized.
- Automatic renewal's "start at login" option is Windows-only.
- One paired Watch per iPhone. Only IPAs that contain both the iPhone host and `Watch/*.app` are supported.
- The signing dependency `apple-codesign-quick` does not declare a licence; see `docs/LICENSE_REVIEW.md`.
