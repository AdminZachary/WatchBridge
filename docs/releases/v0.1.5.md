# WatchBridge 0.1.5

Two more sign-in fixes, both from reports where the app stopped further than it needed to.

## What changed

- **A missing phone-number list no longer ends the sign-in.** When Apple asks for SMS verification, the app fetches the trusted phone numbers first. For some accounts that request is refused, and the app then reported that the account had no trusted number — which was wrong. It now keeps the real reason, and falls back to pushing a code to the trusted devices instead of stopping. The fallback is used once per sign-in, so a rejected prompt cannot loop.
- **`-22411` explains itself.** "This action cannot be completed at this time" is Apple temporarily refusing the developer token, usually because the Apple Developer agreement has not been accepted or the account has been throttled after repeated attempts. The message now says that instead of showing the raw error chain.

## Requirements

**Windows** — Windows 10 22H2 or Windows 11 on x64, Apple Mobile Device Service (iTunes or the Apple Devices app) and the WebView2 runtime.

**macOS** — macOS 11 or newer on Apple Silicon or Intel, without Xcode.

**Linux** — the `usbmuxd` daemon, WebKitGTK 4.1, a Secret Service keyring and xdg-desktop-portal. GNOME and KDE provide the last two by default.

All three need an iPhone already paired with the target Watch, and a cable for the preparation step.

## Installing on Linux

```bash
sudo apt install ./WatchBridge_0.1.5_amd64.deb    # Debian/Ubuntu
sudo dnf install ./WatchBridge-0.1.5-1.x86_64.rpm # Fedora
sudo systemctl enable --now usbmuxd
watchbridge
```

## Installing on macOS

The bundle is ad-hoc signed but not notarized. The first launch is blocked by Gatekeeper: allow it once under **System Settings → Privacy & Security → Open Anyway**, then open the app again.

## Known limitations

- The Windows executable is unsigned, so SmartScreen warns on first run; the macOS bundle is not notarized.
- Automatic renewal's "start at login" option is Windows-only.
- One paired Watch per iPhone. Only IPAs that contain both the iPhone host and `Watch/*.app` are supported.
- The signing dependency `apple-codesign-quick` does not declare a licence; see `docs/LICENSE_REVIEW.md`.
