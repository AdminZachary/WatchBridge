# WatchBridge 0.1.0

WatchBridge prepares Apple Watch developer mode and installs Watch Companion apps from a signed IPA — the half of iOS sideloading that normally needs Xcode on a Mac. 0.1.0 is the first release that ships both platforms from the same source tree.

## Highlights

- **Windows and macOS from one codebase.** Native Apple Silicon and Intel builds, packaged as disk images, with no Xcode installation required to run the app.
- **Watch developer mode preparation.** The app pairs with the Watch through the paired iPhone and requests the Developer Mode switch to appear. Only the reveal action is sent; enabling, restarting and confirming stay on the Watch.
- **Companion installation.** The IPA is checked for an embedded `Watch/*.app` before anything is signed, then re-signed, installed on the iPhone and finally on the Watch over the RSD tunnel.
- **Wi-Fi installs and renewal.** Set up Wi-Fi once over USB, then install and renew without a cable.
- **Automatic renewal.** Re-signs before the seven-day expiry, with tray controls and optional start at login.
- **Localized interface.** 28 languages are bundled; the nine most used are fully translated.
- **Log export.** The log viewer writes everything to a single file for bug reports.

| `watchbridge-windows.zip` | Windows 10 / 11 (x64) | `WatchBridge.exe`, `BUILD.json`, `SHA256SUMS.txt`, `LICENSES.zip` |

Each build records its source commit, lockfile hashes, toolchain versions and the executable checksum, so a download can be traced back to the tree it came from.

## Requirements

**Windows** — Windows 10 22H2 or Windows 11 on x64, Apple Mobile Device Service (iTunes or the Apple Devices app) and the WebView2 runtime.

**macOS** — macOS 11 or newer on Apple Silicon or Intel. The system `usbmuxd` is used directly, so there is no driver to install.

Both platforms need an iPhone already paired with the target Watch, and a cable for the preparation step.

## Installing on macOS

The bundle is ad-hoc signed but not notarized. The first launch is blocked by Gatekeeper: allow it once under **System Settings → Privacy & Security → Open Anyway**, then open the app again. This is expected for an unsigned distribution; a Developer ID certificate and notarization would remove the prompt.

## Known limitations

- The Windows executable is unsigned, so SmartScreen warns on first run.
- The macOS bundle is not notarized, as described above.
- Automatic renewal's "start at login" option is Windows-only; on macOS it reports that it is unavailable.
- One paired Watch per iPhone. Only IPAs that contain both the iPhone host and `Watch/*.app` are supported; independent Watch-only packages are not.
- `Auth error -23782` during sign-in means the selected anisette server reports an old macOS version. Choose a server that reports 13.x.
- The signing dependency `apple-codesign-quick` does not declare a licence; see `docs/LICENSE_REVIEW.md`.

## Verification

Both platforms build in CI, which also runs the `iloader` and `isideload` unit tests. The macOS build has been validated on a physical Apple Silicon Mac; the Windows build has been validated end to end on physical iPhone and Apple Watch hardware.
