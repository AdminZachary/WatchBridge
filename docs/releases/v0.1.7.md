# WatchBridge 0.1.7

Two-factor verification is now a real dialog: you can pick a method, see where the code goes, and ask for it again.

## What changed

- **SMS verification is selectable.** When Apple asks for a code, the dialog lists the account's trusted phone numbers, shows which one is receiving codes, and offers **Send SMS** alongside the trusted-device prompt. **Resend code**, **Use trusted devices** and **Cancel** are available throughout, so an account whose devices never receive a notification has somewhere to go instead of a dead end.
- **Each prompt is matched to its request.** Responses carry a request id, so a late answer to an earlier prompt can no longer satisfy a newer one, and a malformed or unknown-number reply is ignored instead of being accepted.
- **The dialog explains itself.** It names the number the SMS went to, shows the last error Apple returned, and says so when no trusted phone number is available for this sign-in.

Translations for the new strings are included in German, English, Spanish, French, Japanese, Korean, Brazilian Portuguese, Simplified Chinese and Traditional Chinese; other languages fall back to English for these lines.

## Requirements

**Windows** — Windows 10 22H2 or Windows 11 on x64, Apple Mobile Device Service (iTunes or the Apple Devices app) and the WebView2 runtime.

**macOS** — macOS 11 or newer on Apple Silicon or Intel, without Xcode.

**Linux** — the `usbmuxd` daemon, WebKitGTK 4.1, a Secret Service keyring and xdg-desktop-portal. GNOME and KDE provide the last two by default.

All three need an iPhone already paired with the target Watch, and a cable for the preparation step.

## Installing on Linux

```bash
sudo apt install ./WatchBridge_0.1.7_amd64.deb    # Debian/Ubuntu
sudo dnf install ./WatchBridge-0.1.7-1.x86_64.rpm # Fedora
sudo systemctl enable --now usbmuxd
watchbridge
```

## Installing on macOS

The bundle is ad-hoc signed but not notarized. The first launch is blocked by Gatekeeper: allow it once under **System Settings → Privacy & Security → Open Anyway**, then open the app again.

## Known limitations

- The Windows executable is unsigned, so SmartScreen warns on first run; the macOS bundle is not notarized.
- Automatic renewal's "start at login" option is Windows-only.
- One paired Watch per iPhone. Only IPAs that contain both the iPhone host and `Watch/*.app` are supported.
- The signing dependency `apple-codesign-quick` does not declare a licence; see `docs/LICENSE_REVIEW.md`.
